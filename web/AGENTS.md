# Web (the editor)

## Overview

The graph editor: a React single page app built by Vite, served by a Caddy based `web` image. One bundle serves the site root or any sub path, talking to the planner in the online tool or to `api` in managed mode. Root [AGENTS.md](../AGENTS.md) rules apply here too.

## Stack

- React 19, TypeScript 6 (strict, `noUncheckedIndexedAccess`), Vite 8, pnpm 12, Node 26
- React Flow (`@xyflow/react` v12) for the canvas; TanStack Router (file based routes); TanStack Query for catalog, plan and render calls; Zustand for graph and editor state
- `openapi-fetch` with types from `openapi-typescript`
- Styling and components: decided in spec #5, not yet

## Key files

| File | Owns |
|---|---|
| `src/lib/config.ts` | Base path and API root, read from `<meta>` tags at start |
| `src/api/client.ts` | The typed planner client |
| `src/api/planner.gen.ts` | Generated from `contracts/openapi/planner.yaml`, never edit |
| `src/routeTree.gen.ts` | Generated by the router plugin, committed, never edit |
| `src/lib/store.ts` | Zustand editor state |
| `vite.config.ts` | `base: './'` and the `index.html` asset tag rewrite |

## Commands

```bash
pnpm --dir web dev            # or task dev for the whole online tool
pnpm --dir web test           # vitest
pnpm --dir web typecheck
pnpm --dir web lint           # Biome, lint and format check
pnpm --dir web format         # Biome, applying safe fixes
pnpm --dir web generate       # or task generate at the root
pnpm --dir web smoke:browser  # Playwright, used by task smoke
```

## Conventions

- Named exports only; a default export only where a tool requires one.
- PascalCase component files and names, camelCase functions and modules.
- Failures render through `src/components/Failure.tsx`.
- Accessibility WCAG AA: keyboard reachable controls (canvas too), labels, enough contrast.
- Tests: Vitest with Testing Library for logic and components (`src/test/`), Playwright for end to end smoke (`smoke/`).

## Gotchas

- Never add `<base href>`: it breaks React Flow's SVG `url(#id)` edge markers and hash links. Paths come from `basePath` and `apiRoot` in `src/lib/config.ts`.
- `index.html` is a Caddy template at serve time; in tests the meta tags still hold `{{...}}`, so `config.ts` falls back to defaults.
- The build regenerates `routeTree.gen.ts`; CI fails if the build changed tracked files, so commit it.
